# Shorts automáticos

1. Copia una carpeta (p. ej. `gta6-curiosidades`) y edita `guion.json` (cada slide: `tag`, `texto` con `\n` para saltos de línea y `dur` en segundos).
2. Ejecuta: `python3 generar_short.py carpeta/guion.json [musica.mp3]`
3. Sale `carpeta/short.mp4` en 1080x1920, listo para Shorts, TikTok y Reels.

Requiere solo `ffmpeg` y Python 3.
